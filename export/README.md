# Auto škola ADR Refleks – sajt

Statički sajt (HTML + CSS, bez build koraka). Početna stranica je `index.html`.

## Pre objave

1. Zameniti `https://VAS-DOMEN.rs/` pravim domenom u `index.html`, `robots.txt` i `sitemap.xml`.
2. Kada sajt ide uživo, u `index.html` promeniti `<meta name="robots" content="noindex, nofollow">` u `index, follow`.

## GitHub Pages

Settings → Pages → Source: *Deploy from a branch* → grana `main`, folder `/ (root)`.
